    Dressca Frontend アプリケーション 機能一覧¶

    このドキュメントは、Dressca Frontendアプリケーション（AdminとConsumer）の機能一覧をまとめたものです。

    1. 認証・認可機能¶

    1.1 基本認証機能¶

    • ログイン: ユーザー認証を行う機能
    • ログアウト: ユーザーセッションを終了する機能
    • 権限チェック: ユーザーの権限に基づいてアクセス制御を行う機能

    2. 管理者向け機能（Admin アプリケーション）¶

    2.1 商品管理¶

    • 商品一覧表示: 全商品を一覧表示する機能
    • 商品詳細表示: 商品の詳細情報を表示する機能
    • 商品追加: 新しい商品を追加する機能
    • 商品編集: 既存の商品情報を編集する機能
    • 商品削除: 商品を削除する機能
    • 商品カテゴリ管理: 商品カテゴリを作成・編集・削除する機能

    2.2 ユーザー管理¶

    • ユーザー一覧表示: 全ユーザーを一覧表示する機能
    • ユーザー詳細表示: ユーザーの詳細情報を表示する機能
    • ユーザー追加: 新しいユーザーを追加する機能
    • ユーザー編集: 既存のユーザー情報を編集する機能
    • ユーザー削除: ユーザーを削除する機能
    • ユーザー権限管理: ユーザーの権限を設定・変更する機能

    2.3 注文管理¶

    • 注文一覧表示: 全注文を一覧表示する機能
    • 注文詳細表示: 注文の詳細情報を表示する機能
    • 注文ステータス更新: 注文のステータスを更新する機能

    2.4 ダッシュボード¶

    • 売上統計: 売上データを視覚的に表示する機能
    • ユーザー統計: ユーザーデータを視覚的に表示する機能
    • 商品統計: 商品データを視覚的に表示する機能

    3. 一般ユーザー向け機能（Consumer アプリケーション）¶

    3.1 ユーザーアカウント¶

    • アカウント登録: 新規ユーザーアカウントを作成する機能
    • プロフィール管理: ユーザープロフィール情報を管理する機能
    • パスワードリセット: パスワードを再設定する機能

    3.2 商品閲覧¶

    • 商品一覧閲覧: 商品を一覧表示する機能
    • 商品詳細閲覧: 商品の詳細情報を表示する機能
    • 商品検索: キーワードで商品を検索する機能
    • 商品フィルタリング: 条件に基づいて商品をフィルタリングする機能
    • カテゴリ閲覧: カテゴリ別に商品を表示する機能

    3.3 ショッピングカート¶

    • カートへの追加: 商品をショッピングカートに追加する機能
    • カートからの削除: 商品をショッピングカートから削除する機能
    • 数量変更: カート内の商品数量を変更する機能
    • カート内容保存: カート内容をセッションまたはデータベースに保存する機能

    3.4 注文処理¶

    • 配送先情報入力: 配送先住所などの情報を入力する機能
    • 支払い方法選択: 支払い方法を選択する機能
    • 注文確認: 注文内容を確認する機能
    • 注文完了: 注文を確定し、完了する機能

    3.5 注文履歴¶

    • 注文履歴表示: 過去の注文履歴を表示する機能
    • 注文詳細表示: 注文の詳細情報を表示する機能
    • 注文ステータス確認: 注文の現在のステータスを確認する機能

    3.6 お気に入り¶

    • お気に入り追加: 商品をお気に入りリストに追加する機能
    • お気に入り削除: 商品をお気に入りリストから削除する機能
    • お気に入りリスト表示: お気に入りに登録した商品を一覧表示する機能

    4. システム機能¶

    4.1 エラーハンドリング¶

    • グローバルエラーハンドラー: アプリケーション全体で発生する未処理のエラーをキャッチする機能
    • カスタムエラーハンドラー: 特定のエラータイプに対するカスタム処理を提供する機能

    4.2 国際化（i18n）¶

    • 多言語サポート: 複数言語に対応する機能
    • 言語切替: ユーザーが言語を切り替える機能

    4.3 レスポンシブデザイン¶

    • デバイス対応: さまざまなデバイスサイズに対応するレスポンシブなUIを提供する機能
