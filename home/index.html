    AlesInfiny Maia OSS Edition¶

    AlesInfiny Maia OSS Edition は現代の Java システム開発において標準的なアプリケーションアーキテクチャを提供します。 商用のエンタープライズシステム開発から個人開発の小規模なシステムまで、 無償で利用可能です。

    プロジェクト概要¶

    AlesInfiny Maia OSS Edition は、Java システム開発のための標準的なアプリケーションアーキテクチャを提供するフレームワークです。エンタープライズシステムから個人開発まで幅広く対応し、無償で利用できます。

    主な機能¶

    • 標準的なアプリケーションアーキテクチャ: 現代の Java システム開発に最適化されたアーキテクチャを提供
    • サンプルアプリケーション (Dressca): 実装例として参照可能
    • Dressca Frontend の詳細構造
    • 要件別サンプル: 特定の要件に対する実装例を提供
    • 包括的なドキュメント: MkDocs と Wiki.js を使用した詳細なドキュメント
    • テスト自動化: JUnit を使用した単体テストと結合テスト
    • Vue.js サポート: フロントエンド開発のための Vue.js サポート

    セットアップ手順¶

    前提条件¶

    • VS Code (最新バージョン推奨)
    • Docker と Docker Compose
    • Java 開発環境
    • Node.js (Vue.js アプリケーション用)

    ローカル開発環境のセットアップ¶

    1. リポジトリをクローン: 

      git clone https://github.com/your-repo/maia.git
cd maia

    2. Docker コンテナを起動: 

      docker-compose up -d

    3. ドキュメントの閲覧:

    4. Wiki: http://localhost:80
    5. MkDocs: http://localhost:9000
    6. PlantUML: http://localhost:9999

    サンプルアプリケーション (Dressca) の実行¶

    詳細な手順は AlesInfiny Maia OSS Edition | クイックスタート を参照してください。

    使用例¶

    Java アプリケーションのテスト実行¶

    ./gradlew test

    Vue.js アプリケーションのテスト実行¶

    npm run test:unit:consumer
